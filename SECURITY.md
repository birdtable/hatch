# Security

## Reporting a vulnerability

Please report a vulnerability privately, through GitHub's private vulnerability reporting: open the repository's Security tab and choose "Report a vulnerability". Please do not open a public issue for it.

Say what you found and how to reproduce it: the hatch version (`hatch` built from a tag, or the commit), the Go version, the system, and the shortest command line that shows it. Describe the class of problem; a working exploit is not needed.

We will answer within a few days and tell you when a fix is released.

## Supported versions

The latest minor version receives security fixes.
